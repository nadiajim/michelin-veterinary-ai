# Michelin: Veterinary Multi-Agent Clinical Ecosystem

An end-to-end, production-ready prototype for **Michelin**, a veterinary multi-agent clinical ecosystem built for feline medicine, featuring proactive co-piloting for attending clinicians, an empathetic caregiver triage companion, and an in-memory Central Patient Store (SSOT).

---

## 🐾 Ecosystem Roles

1. **"Michelin" (Veterinary Co-Pilot Agent)**
   - **Target User**: Attending Veterinarian (Dr. Andy).
   - **Model**: `gemini-2.5-pro` (deep clinical reasoning & structured output).
   - **Capabilities**: Proactive hypothesis cross-examination, differential audit, longitudinal trend analysis, ambiguous data alerts, and triage escalation inbox.
2. **"Haiiro" (Caregiver Triage Companion)**
   - **Target User**: Feline pet parents / caregivers at home.
   - **Model**: `gemini-2.5-flash` (low-latency empathetic communication).
   - **Capabilities**: Ingests home observations and photos/videos, classifies clinical risk (`RED` / `YELLOW` / `GREEN`), enforces non-negotiable red flags, and escalates directly to Dr. Andy when thresholds are breached.
3. **Central Patient Store (SSOT)**
   - **Architecture**: Unified, thread-safe, versioned in-memory store preventing state drift between Michelin and Haiiro.
   - **Concurrency**: Optimistic concurrency control (`record_version` increment with conflict detection).

---

## 🛡️ Non-Negotiable Medical Guardrails

1. **Zero Hallucination Guarantee**:
   - The system **never** interpolates, guesses, or extrapolates numeric lab values or missing clinical data.
   - All numbers generated by LLMs in clinical summaries, differentials, or citations are cross-referenced with the SSOT. Any unverified number is redacted (`[UNVERIFIED-VALUE-REDACTED]`) and flagged as a `GuardrailViolation`.
2. **Strict OCR / Extraction Protocol**:
   - If any lab metric, image, or text block is blurred, smudged, illegible, or ambiguous, the model must output:
     ```json
     {
       "status": "AMBIGUOUS",
       "flag": "Data unreadable / ambiguous — manual clinical verification required",
       "value": null
     }
     ```
   - Type-level Pydantic v2 validators reject any record that assigns a non-null numeric value to an `AMBIGUOUS` metric.
3. **Feline Domain Nuance**:
   - **Longitudinal CKD Staging (IRIS 2023)**: Evaluates trend direction and adequacy of urine concentration (USG < 1.035). E.g., Creatinine rising `1.4 -> 1.9 -> 2.3 mg/dL` with USG `1.022` is provisionally staged as **IRIS Stage 2 CKD**, even though `2.3 mg/dL` falls within standard laboratory reference intervals (0.6 - 2.4 mg/dL).
   - **Feline Triaditis Detection**: Detects concurrent pancreatic (`fPLI >= 5.4 µg/L`), gastrointestinal (vomiting, weight loss), and hepatobiliary (`ALT`, `ALP`, `GGT`, bilirubin) markers.
   - **Emergency Red Flag Overrides**: Deterministic red-flag rules (e.g., male cat straining to urinate, open-mouth breathing, 3+ vomiting episodes in 24h) **can never be downgraded** by the LLM.

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.10+ (Tested on Python 3.12)
- Virtual environment (`.venv`)

### 2. Install Dependencies
```bash
python -m venv .venv
# On Windows:
.\.venv\Scripts\Activate.ps1
# On Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Optional: Set Gemini API Key
When `GEMINI_API_KEY` is not present, the ecosystem operates in **deterministic fallback mode**, preserving 100% of the medical guardrails and calculation logic.

To enable live Google GenAI SDK structured outputs:
```bash
# PowerShell
$env:GEMINI_API_KEY = "your-google-gemini-api-key"

# Bash
export GEMINI_API_KEY="your-google-gemini-api-key"
```

### 4. Running the Tests
```bash
.\.venv\Scripts\python.exe -m pytest -v
```
All 42 unit, integration, and guardrail tests should pass in under 1.5 seconds.

### 5. Running the API Server
```bash
.\.venv\Scripts\python.exe -m uvicorn michelin_core.api.main:app --host 127.0.0.1 --port 8000 --reload
```

Interactive OpenAPI documentation will be available at:
- **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## 📡 Key Endpoints

### 1. Central Patient Store (SSOT)
- `GET /api/records` - List patient identifiers.
- `GET /api/records/{patient_id}` - Fetch unified multimodal patient record.
- `GET /api/records/{patient_id}/trends/{analyte}` - Calculate verified longitudinal trend without extrapolation (e.g. `creatinine`, `usg`, `weight`).
- `POST /api/records/{patient_id}/labs/extract` - Strict OCR ingestion of laboratory reports.

### 2. Haiiro Triage Companion
- `POST /api/haiiro/triage`
  - Ingests caregiver symptoms, free-text observations, and media.
  - Returns `GREEN`, `YELLOW`, or `RED` triage risk level with caregiver communication and recommended actions.
  - Automatically files and persists an `Escalation` to Dr. Andy when thresholds are breached.

### 3. Michelin Veterinary Co-Pilot
- `POST /api/michelin/cross-examine`
  - Evaluates Dr. Andy's working hypothesis against the SSOT.
  - Provides IRIS staging, triaditis assessment, differential audit, and challenges to hypothesis.
  - Identifies ambiguous labs and data gaps.
- `GET /api/michelin/escalations?status=OPEN`
  - Returns active escalations awaiting Dr. Andy's clinical review.
